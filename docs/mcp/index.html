Local, over stdio

uf mcp is a stdio MCP server (JSON-RPC 2.0, one message per line). Renders run on your GPU.

Claude Code
claude mcp add ultrafast -- uf mcp
Codex · ~/.codex/config.toml
[mcp_servers.ultrafast]
command = "uf"
args = ["mcp"]
Cursor · .cursor/mcp.json, Gemini CLI · ~/.gemini/settings.json, Claude Desktop · claude_desktop_config.json
{
  "mcpServers": {
    "ultrafast": { "command": "uf", "args": ["mcp"] }
  }
}

Documents stay plain JSON files. The server keeps a renderer per document, so repeated frames are fast, and reloads a file when it changes, whether the agent edits it with ultrafast_edit or writes it directly.

Remote, over HTTP

ultrafast serve answers MCP over Streamable HTTP at /mcp, with its API key as a bearer token, for agent frameworks and any client that can't run a local process. It serves the 16 tools that need no local files; they take the document and asset ids instead of file paths; frames and sheets come back as images and exports as download links.

Claude Code, your server
claude mcp add --transport http ultrafast http://localhost:8080/mcp \
  --header "Authorization: Bearer $ULTRAFAST_API_KEY"

A hosted server with OAuth sign-in, for the ChatGPT app and the Claude connector, comes with ultrafast Cloud.

The tools

tooldoes
ultrafast_opsThe op vocabulary: ports, params, types, defaults, docs.
ultrafast_newWrite a template (vertical, title, square, promo, explainer, product) to a path.
ultrafast_checkProblems in a document, static and render-time.
ultrafast_frameOne exact frame, returned as an image.
ultrafast_sheetA labelled contact sheet of frames, returned as an image.
ultrafast_reviewRenders the film and reports unreadable, too-brief, clipped, overlapping or tiny text, unsafe areas and seizure-risk flashing.
ultrafast_inspectWhat is on screen at a time: each element's node, bounds and words.
ultrafast_editApply an edit batch to the document file, atomically.
ultrafast_exportEncode to MP4, MOV (ProRes), WebM, a GIF, a PNG or EXR sequence or sound alone, at any size, frame rate and quality level, transparent where the codec allows.
ultrafast_estimateRendered minutes, GPU seconds and the time to the first byte, before rendering.
ultrafast_batchOne document, a video per row of a CSV or JSON file.
ultrafast_profileGPU milliseconds per render group, for slow films.
ultrafast_beatsTempo, beats, downbeats and onsets of a soundtrack.
ultrafast_voiceoverSpeak a script to WAV with every word's time, for audio and captions.
ultrafast_import_svgAn SVG as an editable component, or added to a document.
ultrafast_decomposeA finished video as an editable document: plate, vector layers with their motion, gradients, type read back as text in its matched font.
ultrafast_match_fontA text node's font, size, baseline, tracking and colour, from a video frame.
ultrafast_ocrThe text in a video frame, with word boxes and a draft of text nodes.
ultrafast_measureGlyph metrics of a line of text.
ultrafast_outlineA line of text as SVG path data.

How agents use them

  1. ultrafast_new or write the JSON; ultrafast_ops when unsure of a param.
  2. ultrafast_check until it's clean.
  3. ultrafast_sheet to see the motion; ultrafast_inspect to find the node behind a pixel.
  4. ultrafast_review; fix what it reports with ultrafast_edit.
  5. ultrafast_export.

The ultrafast skill teaches agents the document and this loop: npx skills add ultrafastmov/ultrafast. In Claude Code, the plugin brings the skill and uf mcp together: claude plugin marketplace add ultrafastmov/ultrafast, then claude plugin install ultrafast@ultrafast.
